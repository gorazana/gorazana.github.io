About the site

A showcase you can inspect.

One canonical catalog. An explicit public projection. A static site with no hidden product claims.

Data, not handwritten badges

The canonical source is Gorazana/ecosystem. Entry definitions, source references, icons, access decisions and recorded release observations feed a deterministic generator. This website publishes only approved fields, not original private research archives, credentials, unpublished code or personal data.

The scheduled build checks the catalog for updates every six hours and can also be run manually. GitHub scheduling can be delayed; the observation timestamp and workflow history are the evidence, not a promise of instant refresh. Access and commercial policy changes remain explicit maintainer decisions.

Security and privacy

No analytics, third-party scripts, remote fonts, payment forms or account logins are embedded. Search runs locally in your browser. GitHub still operates the hosting and may retain access logs under its own policy. The site uses a restrictive content security policy and does not transmit search text to an application server.

GitHub Pages is used for technical project documentation and this informational showcase, not as a storefront or SaaS application. Commercial inquiries link to a maintainer conversation; any future purchase or membership transaction needs an appropriate separate service.

Accessibility and ownership

Semantic pages, visible keyboard focus, responsive layouts, text-labelled badges, reduced-motion support and functional no-JavaScript links are included. Tests of those behaviors are not a blanket accessibility certification. Gorazana’s existing mark and icon family are reused; the identity is not a Goravel endorsement.

Research boundaries

The catalog preserves the original 144 requirements and both supplied module taxonomies. New specifications are authored proposals informed by primary project documentation. Libraries are candidates, not silently installed dependencies. No delivery roadmap or dates are promised.
