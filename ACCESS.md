# Access and contribution policy

Component access is currently **unannounced unless its individual canonical catalog record provides an explicit policy and evidence link**. A private repository is not by itself a membership offer. An observed 0.x release does not imply public access, independent security approval or a stable product.

The display supports Free · public, Members, Commercial and Access unannounced as independent labels. New terms, prices or membership rules require a separate explicit maintainer decision. No catalog code makes that decision automatically.

Ask about access through an issue without posting personal or confidential information. A maintainer can direct a private discussion to a suitable channel. GitHub Watch can subscribe to repository activity. No payment or account credentials are collected on this website.
