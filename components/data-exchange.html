Where this component stops

Not arbitrary SQL import, a spreadsheet calculation engine, unbounded memory ingestion, automatic macro/formula execution or a promise a dry-run preview guarantees later commit under changed business state.

Model and lifecycle

Typed contracts, owned persistence and configuration are preserved in SOURCE_REFERENCE.md, original sections 5-6. Adapt to the actual implementation; these are not applied migrations.

Receive already authorized private file reference → validate type/limits/hash → parse streaming → mapping/field authorization → dry-run validation or durable commit job. Commit revalidates current business constraints and scope, applies one transactional chunk, records receipts, advances cursor. Restart verifies identical source/mapping digest. Export freezes an authorized query boundary, streams rows, protects spreadsheet text, writes artifact then publishes ready. Download rechecks current permission; revoked user cannot fetch last night's file merely knowing its ID. ### Cell interpretation and dry-run truth A string that a spreadsheet opens as a formula is dangerous even when CSV-quoted. The package must test its chosen defense in actual supported spreadsheet software or label the residual limitation; typed XLSX text is preferred. Never evaluate user workbook formulas or macros. Dry-run validates one observed snapshot; before commit, the host can have changed and must be checked again. Exports of learning/HR data require scoped private artifacts and retention controls, not public download URLs.

Operational requirements

CSV and XLSX adapters, local native storage, bounded synchronous small batches. Optional expanded profile: Queued large jobs, resumable chunks, scoped bulk policy, private exports and source/version lineage.

Safety and acceptance

  • Current identity/admission and explicit-deny rules remain authoritative
  • Applied migrations stay immutable; sensitive state and audit share a declared transaction where claimed
  • Failures, retries, resource bounds, partial/unknown effects and source ownership are explicit
