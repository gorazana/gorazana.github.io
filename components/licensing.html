Where this component stops

No home-grown cryptography, global offline seat-count guarantee, anti-piracy certainty, permanent fingerprint of a physical machine, payment processing, hidden telemetry or disabling free/local backups when a paid license expires.

Model & lifecycle

Typed contracts, owned persistence and configuration are preserved in SOURCE_REFERENCE.md, original sections 5–6. Adapt to the actual implementation; these are not applied migrations.

Decode bounded envelope → enforce fixed schema/algorithm → select pinned trusted key by key ID → verify exact signed canonical bytes → validate issuer/audience/device/time/capacity → return typed status. Entitled checks the verified status and signed grants, never a UI flag. Activation persists request identity before network call; timeout after remote acceptance is uncertain and must reconcile using the same key. Expiry restricts paid actions with a clear message while preserving reading/export/backup policy and all free features. ### Operational truth A user controlling the operating system can modify application code, restore old disks and alter clocks. A local verifier can validate a signature and apply a policy; it cannot provide absolute DRM or instantaneous offline revocation. A signed bounded offline lease and server-side benefits are the practical controls. Never store an issuer secret in Wails resources, obfuscated JavaScript or a Go binary. ### Commercial boundaries Billing reports payment/subscription facts. A trusted licensing issuer converts those facts to grants. Features controls rollout; Defender still authorizes the actor. Paid module availability is the intersection of these decisions. A grace period and access to existing data must be documented per feature, not hard-coded as delete-all or deny-login.

Operational requirements

Free base mode plus offline verifier with pinned public keys; no network call needed for unlicensed/free features. Optional expanded profile: Activation service adapter, renewable signed leases, fleet/seat operations, key rotation and managed subscription entitlements.
