Where this component stops

Not a licensing authority, role system, experiment statistics engine, billing ledger or substitute for per-request authorization.

Model & lifecycle

Typed contracts, owned persistence and configuration are preserved in SOURCE_REFERENCE.md, original sections 5–6. Adapt to the actual implementation; these are not applied migrations.

Resolve trusted evaluation attributes → validate definition → apply forced-off kill switch → evaluate bounded rules in documented order → choose stable variant or typed default → return reason/details. Available then checks required entitlement and module gates and the host policy; a successful rollout result alone is insufficient. Provider timeout returns the registered default and an error/health signal; it does not silently enable a premium capability. Cache by immutable snapshot; do not mutate one shared context map per request. ### Stable rollout contract Use `sha256-v1` with four-byte big-endian byte lengths before each UTF-8 namespace, key and subject component; do not concatenate with an ambiguous separator. Bucket 0..9999. Store algorithm version with definitions so an upgrade cannot reshuffle users accidentally. A percentage split is deterministic assignment, not proof that an experiment is statistically valid. Experiment analysis is outside this package. ### No privilege shortcut The controller still calls its permission policy before executing a protected action. `Available` is an aggregate availability service, but a record policy may additionally depend on the specific record and must be checked inside that business transaction.
