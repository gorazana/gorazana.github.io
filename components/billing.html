Where this component stops

Not a general ledger, tax compliance engine, payroll, banking reconciliation product, PCI certification, storage for card PAN/CVV or guaranteed support in every merchant country.

Model & lifecycle

Typed contracts, owned persistence and configuration are preserved in SOURCE_REFERENCE.md, original sections 5–6. Adapt to the actual implementation; these are not applied migrations.

Create draft with exact totals → finalize by CAS and freeze lines → persist payment intent/idempotency key → hosted checkout/provider request → verified callback or server reconcile → compare expected account/invoice/customer/currency/amount → settle payment, invoice/receipt and domain outbox together in the declared store. Domain order/entitlement consumers deduplicate by settlement ID and expose pending reconciliation when in other databases. Refund/reversal is a new audited state transition with entitlement compensation rules; it does not erase the original charge. Provider timeout after request is uncertain until verified. ### Payment and legal boundaries Hosted checkout must keep PAN/CVV out of the host package and logs. Tax, invoice numbering, credit rules and retention vary by jurisdiction and legal entity; the host chooses a policy/adapter and obtains jurisdiction-specific review. Do not label this package ISO-, PCI- or tax-certified because its tests pass. The XOF example is a synthetic consumer example, not a statement that a particular merchant account can process it. ### Same-store versus distributed settlement When the host order and billing records genuinely share one native transaction, provide a typed transaction participant. When they do not, emit a durable settlement event and wait for an entitlement/order receipt. The UI must distinguish payment verified from fulfillment complete. Retrying fulfillment must not repeat the provider charge.

Operational requirements

Invoices and native storage with one configured hosted-checkout provider; no subscriptions required. Optional expanded profile: Subscriptions, seat/usage pricing with explicit metering adapter, multi-provider routing, reconciliation, refunds/reversals and accounting export.
