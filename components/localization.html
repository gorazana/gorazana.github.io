Where this component stops

Not machine translation by default, business-timezone inference, a replacement for native Goravel Lang or a promise of full ICU message support without a tested library.

Model & lifecycle

Typed contracts, owned persistence and configuration are preserved in SOURCE_REFERENCE.md, original sections 5–6. Adapt to the actual implementation; these are not applied migrations.

Resolve permitted locale/timezone per request → find registered namespace → evaluate explicit acyclic fallback chain → fetch published immutable message → validate/format parameters with selected engine → return text for context-aware escaping by renderer. Never translate an HTML fragment and mark it trusted by default. Publication validates the entire candidate catalog and atomically swaps a version pointer; running requests keep their previous snapshot. Date and currency formatting require explicit semantic input, not ambiguous strings. ### Native feature first Audit the installed native localization API in Phase 0 and map each requested capability to it. If native lookup already provides a behavior, delegate rather than implement a parallel competing store. A module contributes a namespace and bundled fallback language; the host chooses enabled locales. A translation key must not contain a private student ID or user token.

Operational requirements

Native file catalogs with validation/extraction tooling; no database or network required. Optional expanded profile: Optional catalog review database, scoped overrides, translation import workflow and automated locale completeness reports.
