Read the three axes

Availability

Research: a proposed contract, not software you can install. Source preview: a repository exists, but no matching canonical release is recorded. Available · 0.x preview: a nondraft release was observed and its tag’s Go module declaration matches the current repository. This does not imply independent security approval. Coming-soon dates are not invented.

Access

Free · public requires explicit terms and public source. Members requires a recorded membership/access policy. Commercial requires approved terms and a real contact route. Access unannounced means no such decision has been recorded; a private repository alone is not a paid membership.

Version

Only verified canonical-module releases are displayed as releases. Drafts, mismatched historical namespace tags and 1.x versions are rejected. Prereleases are labeled. The visible timestamp records when data was checked, not a continuous verification claim.

Updates

Catalog and recorded-version changes are read from the canonical ecosystem repository by the publishing workflow. Public repository releases can refresh at build time; private observations require the authenticated maintainer refresh or an explicit evidence update. Browser code never receives an API token.
